a scale-factor synthetic data generator, change data capture (DMS) to the
Offers Platform, and the file exchange with it.

> ABC Bank is fictional. All data in this repo is synthetic.

Project-wide docs (roadmap, business problem, ADRs) live in
[offers-platform-workspace](https://github.com/Lakshmi100/offers-platform-workspace).
